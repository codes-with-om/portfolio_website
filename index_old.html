GCP Scalable Web Infrastructure

Production-style scalable web infrastructure built on Google Cloud Platform, designed to provide reliable traffic distribution, automated scaling, secure networking, and infrastructure managed through Terraform.

  • Designed custom GCP VPC and subnet architecture with Compute Engine instances managed through Terraform
  • Built reusable Instance Template and Managed Instance Group architecture with Nginx deployed through startup scripts
  • Configured Cloud Router, Cloud NAT, IAP SSH access and firewall rules for secure connectivity and private outbound internet access
  • Implemented Health Check and Backend Service integration for the managed instance group
  • Configured Google Cloud Load Balancer for traffic distribution across healthy VM instances
  • Implemented Managed Instance Group autoscaling with scale-out and scale-in based on workload demand
